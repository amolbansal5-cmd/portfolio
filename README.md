# Amol Bansal — 3D Developer Portfolio

A responsive React + Vite portfolio inspired by the supplied light-grey / purple reference. It includes a live Three.js hero object, GSAP scroll reveals, parallax movement, project cards, skills, experience and contact links.

## Run locally
1. Install Node.js 18+.
2. Open this folder in a terminal.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL printed by Vite.

## Build for deployment
Run `npm run build`. The production site is generated in `dist/`.

## Personal details to verify before publishing

- Confirm the education dates and university display name.
- Add a professional headshot if you want a portrait instead of the abstract 3D hero.
- Add your preferred public contact email if you want an email button.
- Review the CallURL project description to ensure it does not reveal confidential client or company information.

## Deploy
This is a standard Vite app and can be deployed to Vercel, Netlify or any static hosting provider. For Vercel, import the repository and use:
- Build command: `npm run build`
- Output directory: `dist`
